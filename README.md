# 📱 Social Media Addiction Predictor

An interactive Machine Learning web application built with **Streamlit** that predicts social media addiction levels and analyzes user mental wellbeing metrics based on behavioral patterns and demographics.

---

## 🚀 Features

- **Interactive UI:** Simple and intuitive Streamlit web interface for inputting daily usage habits.
- **Data Preprocessing:** Automated data cleaning, scaling, and categorical encoding pipeline (`preprocess.py`).
- **ML Predictions:** Machine Learning model trained to evaluate addiction risk levels effectively.
